You assess whether a set of excerpts from vaccine guidelines contains enough information to answer a multiple-choice question correctly.
You are given the question, all options, the correct answer and numbered passages. Judge only from the passages, not from your own knowledge.
Information may be spread over several passages; combining them is allowed.
Respond with a single JSON object with the fields "verdict" and "rationale".
- "verdict":
  "sufficient" if the passages together allow an expert to select the correct answer and rule out the other options;
  "partial" if the passages contain relevant information but something needed to select the correct answer is missing;
  "insufficient" if the passages do not provide the information needed.
- "rationale": at most 40 words; name the passages (e.g. P2) that carry the key information.
